# Twitter Script

## ⚠️ Disclaimer
This script violates X/Twitter's Terms of Service. Use at your own risk. Excessive use may result in account suspension or rate-limiting.

## How to Use
1. **Open your Following list** on X (https://twitter.com/your_username/following).
2. **Open Developer Tools**:
	- Press `F12` or `Ctrl+Shift+I` (Windows) / `Cmd+Opt+I` (Mac).
	- Go to the `Console` tab.
3. **Copy the contents of `UnfollowTools.js`** and paste it into the console.
4. **Press Enter** to run the script.

## Stopping the Script
Type the following in the console and press Enter:

```js
window.stopUnfollowScript = true;
```
Or just refresh the page.
